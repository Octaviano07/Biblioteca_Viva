📚 Biblioteca Viva — Blog V1

Biblioteca Viva — Blog V1 is an early version of a small literary blog created as a frontend web development project.

The project was designed to experiment with HTML, CSS, and JavaScript while creating a simple and immersive space for reading and displaying literary content.

This version was later expanded into a more complete Flask-based application in the "main" branch.

---

✨ Features

- 📖 Display literary posts
- 📝 Individual post pages
- 🔄 Dynamic post rendering with JavaScript
- 🗂️ JavaScript-based post data
- 🎨 Custom styling

🧠 How It Works

The blog does not use a backend or database.

Instead, the posts are stored as JavaScript data in "data.js". JavaScript is then used to dynamically display the available posts and their individual content.

The "post.html" page uses a URL parameter to determine which post should be displayed.

This approach provided a simple way to experiment with dynamic content before introducing a backend.

🚀 Getting Started

Because this is a frontend-only project, no Python environment or database is required.

1. Clone the repository

git clone https://github.com/Octaviano07/Biblioteca_Viva.git
cd Biblioteca_Viva

2. Open the project

Open "index.html" in a web browser.

For a better development experience, you can also use a local development server such as the Live Server extension in Visual Studio Code.

🌿 Project Evolution

"blog_V1" represents the first stage of Biblioteca Viva.

The project started as a simple frontend blog and was later expanded into a Flask application with a backend, database, authentication, CRUD functionality, and image uploads.

The evolution can be summarized as:

Frontend Blog
     ↓
HTML + CSS + JavaScript
     ↓
Dynamic Post Rendering
     ↓
Flask Backend
     ↓
SQLite Database
     ↓
Authentication + CRUD + Image Uploads

The "main" branch represents the more advanced version of the project.
