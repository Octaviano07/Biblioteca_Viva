# Biblioteca_Viva/atualizado
Biblioteca Viva é um espaço digital de expressão literária que combina tecnologia e escrita criativa. Construído com HTML, CSS e JavaScript, o projeto simula um mini-sistema de blog dinâmico, oferecendo uma experiência de leitura envolvente, minimalista e emocionalmente imersiva.
A versão 2 agora oferece back-end, com login, edição de posts, adicionar imagem e opção deletar.
